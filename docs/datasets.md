# Datasets

## Canonical data directories

- Generated extension datasets: `data/generated/extension_datasets/`
- Raw extension sources: `data/raw/extension_sources/`

## Notes

- `tools/data_generation/generate_extension_datasets.py` writes train/test CSV files into `data/generated/extension_datasets/`.
- Credit card fraud preprocessing expects `data/raw/extension_sources/creditcard.csv`.
