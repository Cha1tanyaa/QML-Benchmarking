# Results

## Canonical results directories

- Extension phase results:
  - `results/extension/phase1/`
  - `results/extension/phase2/`
  - `results/extension/phase3/`
- Original paper results:
  - `results/paper/original_study/`

## Notes

- Hyperparameter search outputs are written under each phase folder in a `results/` subdirectory.
- Benchmark summaries are written as `benchmark_best_hyperparams.csv` in each phase root.
